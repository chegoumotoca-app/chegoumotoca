V22 - correção de deploy Vercel

Esta versão foi ajustada para ficar mais parecida com a v21 que já subia corretamente na Vercel.

Alterações de empacotamento:
- removido package-lock.json do ZIP
- removido vercel.json que forçava npm ci
- removido .npmrc
- removido engines/packageManager do package.json
- projeto direto na raiz do ZIP
- sem node_modules, sem .next e sem .git

Motivo:
A v21 subia usando o comportamento padrão da Vercel e reaproveitava cache. A v22 anterior levou package-lock/engines/vercel.json e a Vercel passou a reinstalar dependências em um caminho que travou com o erro npm: Exit handler never called.

Para subir:
git init
git branch -M main
git remote add origin https://github.com/chegoumotoca-app/chegoumotoca.git
git config user.name "chegoumotoca-app"
git config user.email "chegoumotoca@gmail.com"
git add .
git commit -m "fix: v22 sem lockfile para deploy na vercel"
git push -u origin main --force
