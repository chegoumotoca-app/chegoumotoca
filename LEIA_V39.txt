Chegou Motoca v39

Foco desta versão:
- Validações de cadastro: confirmar senha e bloqueio de dados duplicados.
- Duplicidade global: usuário, e-mail, WhatsApp, CPF/CNPJ e placa não podem ser repetidos em contas ativas ou pendentes.
- Normalização de telefone/documento para evitar cadastro duplicado com formatações diferentes.
- Cadastro com alerta de pendências, confirmação final e mensagem de sucesso com redirecionamento.
- Bloqueio de cadastro enquanto usuário comum já está logado, evitando misturar conta de motoboy e estabelecimento.
- Logout real usando a mesma função em botões laterais e menu de perfil.
- Sessão com expiração aproximada de 1 hora sem atividade após fechar/abandonar a página.
- Correção do bug visual da string verde na área de Bag aceita: imagem/token/base64 não deve ser renderizado como texto.
- Rodapé com logo Chegou Motoca e espaçamento melhor para mobile/PWA.
- Avaliações do entregador começam a virar reputação: média, total de avaliações, tags principais e comentários no histórico/conferência.
- Painel admin com som para novos cadastros/créditos/divergências e confirmação antes de aprovar cadastro/crédito.
- Página de avaliações/sugestões com e-mail e WhatsApp opcional, pronta para integração com painel admin.

Antes de testar:
1. Rode no Supabase SQL Editor:
   chegoumotoca_v39_validacoes_sessao_avaliacoes.sql

2. Suba o projeto para o Git/Vercel.

Comandos sugeridos no CMD:
cd /d C:\Users\Administrator\Desktop\kevin\chegou_v39_validacoes_avaliacoes_sessao

dir package.json

git init
git branch -M main
git remote remove origin
git remote add origin https://github.com/chegoumotoca-app/chegoumotoca.git
git config user.name "chegoumotoca-app"
git config user.email "chegoumotoca@gmail.com"
git add .
git commit -m "feat: v39 valida cadastros sessoes e avaliacoes"
git push -u origin main --force
